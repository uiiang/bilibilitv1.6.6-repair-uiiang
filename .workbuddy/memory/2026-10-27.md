## 无痕播放/进度状态收敛（VideoDetailActivity）

**背景**：定义「每次播放只看当前勾选 + 当前是否有播放历史，不记忆上次选择」，原实现有 4 处偏差。

**改动（仅 `mybv/java/classes/com/bilibili/tv/ui/video/VideoDetailActivity.java`，+73/-33）**
1. 新增唯一判定点 `applyNoHistoryState(detail, resetWhenNoHistory)`：
   - `hasHistory = mHistory != null && mHistory.mCid > 0`（原判据 `mProgress != 0` 会把"看过但停在 0 秒"当成无进度）
   - 有历史 → 强制 `sNoHistoryPlayMode=false` + 复选框不勾 + 布局 GONE
   - 无历史 → 仅 `reset=true` 时按全局默认给初值；`reset=false` 时保持用户当前勾选（避免播放返回后把刚取消的无痕又勾回来）
2. `initDefaultPlayButtons` 改调 `applyNoHistoryState(detail, true)`，删除原有 30 行判定/显隐代码。
3. `updateHistoryDisplay` 在 `mHistory != null` 后先 `applyNoHistoryState(detail, false)`，并删掉原来单独的 `noHistoryPlayBtnLayout.setVisibility(GONE)`——修复「历史异步到达（PGC loadHistory / force 校准 / fallback）后按钮被隐藏但勾选仍为 true → 无痕静默生效且无法取消」。
4. `onDestroy` 复位 `sNoHistoryPlayMode=false`，阻断跨页面串味（xg 的 7 个播放入口都读该静态字段，BangumiDetailActivity / aft 下载页入口会继承别的视频的勾选）。

**验证**：`build.ps1` 全链路通过（javac+dx+baksmali 58.6s / apktool 29.1s / 签名 2.5s，TOTAL 91s，EXIT=0），产物 `mybv.apk` 10.8MB；新日志串 `[NO_HISTORY_STATE]` 已出现在 `mybv/smali/.../VideoDetailActivity.smali`。

**待定（D5，未改）**：仍保持「有进度即隐藏无痕按钮」（源自提交 d826a514 的原始设计），即老视频无法无痕复看；若要改成常显+默认不勾，需另行拍板。
