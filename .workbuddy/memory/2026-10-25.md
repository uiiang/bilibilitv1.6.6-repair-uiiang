## 视频点播页 无痕/进度/心跳 流程分析（bilibilitv1.6.6-repair-uiiang）

反编译 Java 在 `mybv/java/classes/`，关键类：
- 无痕判定：`ResolveResourceParams.mNoHistoryPlay` 为唯一开关。UI 复选框 `VideoDetailActivity.sNoHistoryPlayMode`（"无痕"按钮）→ `xg.java` 多处写入 `mNoHistoryPlay`。三处 `if(mNoHistoryPlay) return` 拦截：心跳 `zn.a`、进度 `zq.a`、完成 `yb.reportCompleted`、起播事件 `zk.a`。
- 进度上报（历史）：`zq.a(context,avid,cid,sid,epid,playMethod,progress,realtime,noHistoryPlay)` → `BiliPlayerHistoryService.reportProgress` POST `/x/v2/history/report`。调用方：① `xj.a()`（30s 定时器，BUFFERING_END 启动 `a(...,30000L)`；距上次 >=30s 才报；末尾5s或直播则 progress=-1）② `yb.onCompletion`→`reportCompleted()` 上报 progress=-1（已看完）。另 `zk.a`→`zq.a(String...)` 是 `app_play` 起播埋点（不同重载）。
- 心跳：`zn.a(...)` → `HeartbeatApiService.webHeartbeat` POST `/x/click-interface/web/heartbeat`（aid/cid/sid/epid/played_time/realtime/start_ts/type/sub_type/quality/video_duration/csrf/cookie）。调用方 `yb.c(z,i,i2)`（播放/暂停/缓冲/seek/完成事件）。`zo` 为会话计时器：`a()=start_ts`、`c()=realtime`、`a(int)=max进度`、`h()=暂停/i()=恢复/g()=复位`。`HeartbeatApiService.a(ParamsV2)` `/x/report/heartbeat/mobile` 在代码中未被调用。
- 修复点（本分支）：`yb`/`xj` 把起播/首跳上报延迟到首次 BUFFERING_END（画面真正渲染），不再 loading 阶段上报；`onCompletion` 补发 progress=-1 解决连播导致历史显示完整时长而非"已看完"。

注意：`xj` 与 `yb` 同为 `xh` 子类、并行挂在同一播放器上；`xj` 管跳过+30s进度，`yb` 管心跳+起播/完成。

## 无痕按钮"隐藏文字后复选框偏左不居中"根因分析与修复（已落地，build.ps1 通过）
- 现象：未选中隐藏"无痕"文字后，复选框右侧边距明显大于左侧，未居中。
- 根因：`refreshNoHistoryLabel()` 用 `setText("")` 清空，但承载文字的 `noHistoryPlayBtn`(DrawTextView) 仍占位且残留 `android:layout_marginRight=px_26`（见 activity_video_detail.xml:331）；叠加 CheckBox 的 `marginRight=px_10` 与 LinearLayout `minWidth=px_100` 把多余宽度堆右侧，导致 checkbox 偏左。
- 重播按钮参考（正确做法）：`d.onFocusChange`(4570) 对 `video_re_play_btn` 用 `setVisibility(VISIBLE/GONE)` 而非 setText；布局默认 `visibility="gone"`(361)。GONE 让 view 连同 margin 脱离布局流。
- 差异：重播隐藏后只剩 1 个对称 margin 图标；无痕隐藏后剩 1 个 CheckBox（marginLeft=20/marginRight=10 不对称 + scaleX/Y=1.3），仅照搬 GONE 仍偏左。需同时：文字改 GONE + 调 checkbox margin 对称 / 降 minWidth 才能居中。
- 落地（2026-10-25，已构建通过）：① `refreshNoHistoryLabel()` 将 `setText("无痕"/"")` 改为 `noHistoryPlayBtn.setText("无痕")` + `setVisibility(show?VISIBLE:GONE)`（smali:9238 方法体，const/4 v0=0x0 VISIBLE、const/16 v2=0x8 GONE）；② 布局 activity_video_detail.xml 无痕块：`minWidth` px_100→px_80、CheckBox `marginRight` px_10→px_20（与左侧 px_20 对称）、`video_no_history_play_btn` 默认 `visibility="gone"`。隐藏文字后 GONE 让 textview 连同 marginRight=26 脱离布局流，仅剩 checkbox（margin 20/20 对称 + minWidth 兜底）自然居中，与重播按钮实现对齐。
